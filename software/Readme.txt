Для тестирования модуля памяти используется консольное приложение test_mu.exe
При запуске приложения вторым параметром указывается имя COM-порта, например,

   test_mu.exe COM3

Настройки COM-порта (файл COM_Settings.jpg) меняются в Диспетчере устройств Windows.
Используются следующие установки:
- скорость передачи:               38400 Бод
- число бит данных:                8
- проверка на чётность/нечётность: нет
- число стоповых битов:            1

В режиме записи данных в модуль памяти происходит считывание из файла w_data_mix.txt
В режиме чтения данных из модуля памяти происходит запись в файл r_data.txt
